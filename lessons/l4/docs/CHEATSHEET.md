# L4. Краткая справка

[Задание A4](../README.md) · [Гайд](GUIDE.md) · [Интерактивная модель](interactive.html) · [Слайды](slides-standalone/slides.html)

## Путь действия

```text
ввод → действие с данными → общее правило → новое состояние → отображение
```

Интерфейс принимает ввод и показывает ответ. Правило решает, допустимо ли действие и как изменятся данные. Владелец состояния связывает части. Внешняя операция обращается к файлу, хранилищу или серверу и может завершиться ошибкой.

## Чистое правило

- Одинаковые данные на входе дают одинаковое решение.
- Функция не читает DOM, сеть, часы или хранилище.
- Старые объекты и массивы не меняются на месте.
- Результат и отказ выражаются типами, например discriminated union.
- Проверить такую функцию можно без рендера React.

## В React

```tsx
// Внутри React-компонента
const [state, dispatch] = useReducer(reducer, initialState);
```

`dispatch` сообщает о действии; reducer возвращает новое состояние. Компоненты могут передавать действие через callback. `useState` с чистыми типизированными функциями тоже подходит, если переходы ясны.

- Общие данные держит один владелец; карточка и обзор читают одну попытку.
- Локальное состояние подходит деталям, нужным только одному участку интерфейса.
- `Context` доставляет значение по дереву, но сам не является владельцем состояния.
- `useEffect` синхронизирует React с внешней системой. Кнопка обычно запускает пользовательскую операцию из обработчика.
- Значения из JSON/API проверяются во время выполнения; TypeScript-аннотация этого не делает.

## A4

Обзор показывает ответы до завершения. Очистка из карточки и обзора меняет одну попытку и одинаково пересчитывает отображаемые ответы, прогресс и пропуски. После `submitted` изменение запрещено и интерфейсом, и правилом обработки. Сохраните формат `Answer` и `taskId` из A3.

`useReducer` рекомендован. Context, библиотеки состояния и автоматические тесты не обязательны. Количество файлов, слоёв и хуков не оценивается. HTTP и восстановление после перезапуска не входят в A4.

## Следующий шаг

В L5 клиент вызывает сервер по HTTP. `attemptId` — указатель на серверную попытку: после перезапуска клиент получает `Attempt` через API. Сам HTTP не является хранилищем; отсутствие или непринятый сервером id нужно обработать отдельно.
