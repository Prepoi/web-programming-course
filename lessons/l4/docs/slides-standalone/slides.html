После L3: состояние и его владелец. Теперь — общие правила и связь частей.

Одно действие — несколько мест

  • Мы можем переименовать документ из списка или редактора.
  • Меню и горячая клавиша вызывают одну команду.
  • Правило имени должно оставаться общим.

Кто за что отвечает

вводобщее действиерезультат
  • Экран передаёт id документа и новое имя.
  • Логика возвращает новый список или отказ.
  • Сохранение в файл или хранилище — отдельная операция.

Проверка имени

checkDocumentName(name) → NameCheck
  • Ограничение длины задано в модели.
  • Список и редактор не выбирают его сами.
  • Результат — очищенное имя или причина отказа.

Результат переименования

renameDocument(documents, id, name)

type RenameResult =
  | { ok: true; documents: DocumentRecord[] }
  | { ok: false; message: string };

Успех даёт новый список. При отказе старый список остаётся.

Один путь в React

список / редакторdispatch(rename)reducerрезультат
  • Оба места передают id и новое имя.
  • Reducer вызывает renameDocument.
  • Оба места показывают один результат.

Действие пользователя и внешняя операция

«Сохранить» → обработчикuseEffect → синхронизация
  • Явное сохранение запускается из обработчика.
  • Эффект синхронизирует React с внешней системой.
  • Отказ записи не должен стирать ввод.

Меняем одну часть приложения

saveDocument(document) → SaveResult
  • Локальная запись и учебный отказ имеют один вход.
  • Правила имени и данные документа сохраняются.
  • HTTP потребует ожидания ответа и новых состояний на L5.

Context и библиотеки состояния

  • Context доставляет данные по дереву; он не владеет ими.
  • Redux и Zustand помогают организовать общее состояние по-разному.
  • Для небольшого приложения могут подойти useState или useReducer.

Применение в A4 и следующий шаг

  • Очистка из карточки и обзора меняет одни и те же ответы.
  • submitted запрещает изменения и в интерфейсе, и в логике.
  • В L5 по attemptId запрашивается подтверждённый Attempt.

HTTP — способ обмена сообщениями, а не место хранения. P5 проверяет A4.
