Термины

В React компонент получает props от родителя, а выбор можно хранить в state. Для элементов списка React использует key, чтобы сопоставлять их между обновлениями. Mount связывает корень приложения с DOM; Vite запускает модульный проект.

Ниже обычный JavaScript иллюстрирует поток данных и выбор. Он не проверяет типы и не демонстрирует работу React с key; эти части разобраны в гайде. Пример с книгами не является решением A2.

Попробуйте выбрать другую книгу, очистить выбор и изменить заголовок. После каждого действия назовите значение, которое изменилось, и часть экрана, которая его показывает.
